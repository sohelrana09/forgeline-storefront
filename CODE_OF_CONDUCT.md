# Code of conduct

Forgeline follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and discussions. Harassment, personal attacks, discriminatory language and publishing other people's private information are not accepted.

## Reporting

If someone's behaviour is a problem, contact the maintainer privately through [GitHub](https://github.com/sohelrana09). Reports are handled confidentially. The maintainer may remove comments, issues or pull requests, or block accounts, that break this code of conduct.
